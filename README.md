# integrating-ai

## Windows Instructions
Cloning the Repository - `git clone https://github.com/ryan-avancena/integrating-ai`
Creating a Virtual Environment - `python -m venv venv` or `py -3.11 -m venv venv`
Activating the Virtual Environment - `./venv/Scripts/activate`
Installing Libraries inside the Virtual Environment - `pip install -r requirements.txt`

## MacOS Instructions
Cloning the Repository - `git clone https://github.com/ryan-avancena/integrating-ai`
Creating a Virtual Environment - `python3 -m venv venv` or `python3.11 -m venv venv`
Activating the Virtual Environment - `source ./venv/bin/activate`
Installing Libraries inside the Virtual Environment - `pip install -r requirements.txt`

## Programs to Run
Checking available cameras that are accessible - `test_camera.py`
Mediapipe files - `mediapipe_gestures.py` and `mediapipe_face_detection.py`

## If you got Whisper running on your machine or have a Gemini key
Whisper - `whisper_demo.py`
Gemini - `gemini.py`

## Leaving the Virtual Environment - `deactivate`
